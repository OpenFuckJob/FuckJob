# OfferFlow v0.1.20

本版本两条主线：BOSS 侧新增招聘者活跃度与猎头岗位过滤，把投递集中到更可能回复的岗位；新增「测试模式」，把筛选、打招呼、回复三条链路拆成可逐环节查看的报告，配合 Agent 调用轨迹在页面里就地调提示词。另外修掉一个长期存在的配置丢失问题：改完设置重启就回到默认值。

## BOSS 招聘者活跃度过滤

- 新增「BOSS 活跃度过滤」（配置中心 · 求职设置 · 岗位筛选）：给招聘者活跃度设最低门槛，低于门槛的岗位跳过。门槛从「在线」「刚刚活跃」「3 日内」「本周」一路排到「近半年」「半年前」与「不筛选」，界面按一条从更活跃到更不活跃的刻度轴呈现，并说明当前门槛右侧哪些岗位会被跳过。
- 活跃度文案的识别覆盖「N 天／周／个月内活跃」与「N 天／周／个月前活跃」两种写法，也认「半月前」「四星期前」这类表达；中文数字与「个」字后缀都能解析。归档一律按流逝时间算，「7 天前活跃」不再被误判成低于「本周活跃」。
- 活跃度只在当前岗位卡片、以及详情页的招聘者信息容器内读取。此前读不到会退化成整页搜索，可能把别的卡片的活跃度、甚至岗位描述里的「在线办公」当成当前招聘者的状态。
- 读不到活跃度时按不满足门槛处理并在日志写明原因；每轮结束的统计新增「活跃度不足」与「猎头岗位」两类跳过计数。

## BOSS 猎头岗位过滤

- 新增「BOSS 猎头岗位过滤」开关（默认关闭）：带猎头标识的岗位卡片在点开之前就跳过，不会被平台标记为已浏览，也就不会因为这次跳过而永久放弃。

## 测试模式

- 新增「测试模式」，替换原有的对话调试页。入口收进「配置中心 · 系统能力」，与大模型、浏览器环境并列，顶层页签留给日常求职主流程。
- 页面按「选链路 → 备场景 → 看结果」三步走，每趟只测一条链路：筛选（正则 → 语义复核）、打招呼（决策 → 序列组装 → 发送体检）、回复（闸门 → 路由 → 决策 → 意图校正 → 发送体检）。要填什么由链路推出来，结果先给结论再给明细。
- 每个环节给出通过／拦截／跳过与原因，拦截原因写成用户看得懂的话并直接铺在行下。流水线十个环节固定全渲染，没跑到的保持灰态，能一眼看出链路断在第几步。
- 全部复用真实运行的同一批函数，不另写一套判断。旧调试入口自己拼参数还漏了 chat_history，导致调试看到的效果和真跑出来的不是一回事。
- 简历入口状态与窗口内已回复条数改为可填参数。旧调试页把它们写死成「未知」和 0，意图校正与闸门的分支根本测不到，而那正是最需要复现的地方。
- 聊天沙盘可以切换 HR 与我方两种身份说话，从而造出「最后一条是我方消息」的对话，触发闸门的不重复发送分支。
- 提示词在页面里就地编辑、立刻重跑，改动只作为覆盖参数带出去不落盘，满意后再按方案 id 写回。
- 岗位、对话、会话现场在三条链路间共用，切链路不清空、不必回退；切到别的配置分组时页面只隐藏不卸载。

## Agent 调用轨迹

- 新增 Agent 调用轨迹，埋点收在所有大模型用途共用的执行循环出口上，新增用途也不会漏接。每轮记下实际送出的提示词、净化后的输出、模型、token 用量与判定结果，供测试模式调提示词。
- 模型调用失败、以及提示词模板漏填变量这类准备阶段的失败同样留痕——后者正是此前猎聘自动回复整个平台静默失效的根因。
- 轨迹只驻内存（环形缓冲 200 条），随进程退出即丢，不落盘：这些内容包含简历与对话原文，确实敏感。
- 轨迹面板按轮次切换，返工轮相对上一轮追加的内容做高亮。

## 修复

- 改完配置重启就回到默认值：配置解析从逐字段搬运改成整份反序列化。此前 analysis_config、reply_polling_config、periodic_delivery_config、humanize_config 四段被整段丢掉——保存当次一切正常（前端拿的是后端返回的内存对象），重启走一遍解析才暴露。手工搬运只保留三处真正的版本迁移，并补齐各配置块的 serde 默认值，避免少一个键就整份配置加载失败。
- 顶层配置镜像漏同步分析策略：顶层镜像里长期躺着一份永不更新的分析配置。目前没有用户可见症状，但违反了「顶层是默认方案镜像」的约定；改为把规整后的顶层重新投影成方案卡与默认方案整体比对，以后漏同步会当场变红。

## 文档

- 官网新增使用教程页：声明、安装、浏览器环境与大模型、简历、岗位筛选、打招呼与自动回复提示词、岗位分析、启动运行，加上常见问题，两段提示词模板带复制按钮。内容与 `docs/user/README.md` 一致，该目录一并纳入版本管理，Pages 工作流同步拷贝教程页与截图。

## 注意

- BOSS 活跃度过滤默认开启，门槛为「本周活跃」。升级后 BOSS 投递会跳过本周未活跃的招聘者，以及活跃度读不出来的岗位，投递量可能明显下降。想保持旧行为，到「配置中心 · 求职设置 · 岗位筛选」关掉该开关，或把门槛调成「不筛选」。
- 原「对话调试」页签已删除，能力由测试模式完全覆盖。
