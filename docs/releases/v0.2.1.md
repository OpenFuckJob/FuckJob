# OfferFlow v0.2.1

`v0.2.1` 是针对 `v0.2.0` 大版本的一次稳定性与真机实测修复版本：基于真实 BOSS 沟通页只读实测与全链路 QA 审计，集中修复零点击状态同步、全新安装配置、Webhook 推送、反封号过滤与暗黑模式等一批核心体验问题。

## 零点击状态同步真机实测与修复

- **BOSS 零点击同步双接口拼接与 MQTT 红点融合**：同步监听并拼接 `geekFilterByLabel`（真实岗位名与工作城市）与 `getGeekFriendList.json`（真实岗位 ID 与最新消息方向），不再误将 HR 头衔当作岗位名；新增首屏 4.8s MQTT 未读红点等待窗口，精准融合 `.notice-badge` 可见红点数，两轮同步完全幂等且完整保留手机端/网页端未读红点；首次冷加载沟通页超时放宽至 45 秒；历史聊天补录不再消耗今日投递安全配额。
- **猎聘零点击同步修复**：修正页面请求记录器读取键名与 HTTP 状态校验，补齐打开沟通抽屉前的水合重试与后续分页 DOM 兜底，点开未读后自动清零本地未读角标。
- **状态存储原子化与单飞保护**：`sync_platform_status` 增加单平台防重入保护与浏览器租约守护，`sync_state` 改用原子写入与语义去重，避免重复写盘与并发覆盖用户手工编辑的备注和阶段。

## 新手体验、看板与暗黑模式修复

- **全新安装默认配置生效**：修复首次启动迁移未加载内置默认配置的问题，新用户安装即自动启用标准拟人化节奏、同公司建联上限与内置打招呼配置。
- **新手引导与基础设置修复**：修复首次引导「默认屏蔽水岗」未选中预设的问题；跳过 AI 配置时自动切换为非 AI 固定开场白模式，不再卡住投递；修复基础设置固定开场白粘贴清空/吞首字问题，并在基础设置中展示可编辑的公司屏蔽词。
- **看板交互与导出补全**：修复看板拖拽回退阶段后被自动弹回的问题；CSV / Markdown 导出合并零点击同步到的最新消息与阶段状态，并补充 CSV 公式注入防护；备份与恢复纳入 `sync_state.json`，导入配置后前端自动重载且自动修复跨设备浏览器路径。
- **暗黑模式全量修复**：彻底消除高级设置菜单、选项卡片、设置行 hover、引导页 AI 配置、周期抽屉及分析报错框中的白底白字对比度问题；首页今日战报条支持实时刷新并准确计入同步约面数。

## Webhook 通知与反封号护栏加固

- **Webhook 业务错误校验与全事件覆盖**：飞书 / 企业微信 / 钉钉 / Bark 在 HTTP 200 响应下严格校验业务错误码，修复 Bark 空正文与尾斜杠路径问题；补齐 AI「转人工」入队通知及验证码/风控熔断/登录失效的 `RiskAlert` 推送。
- **多平台过滤与薪资解析修复**：补齐 BOSS / 猎聘打招呼失败后的拟人停顿；猎聘支持列表前置过滤 + 完整 JD 复验正则规则，修复 `K8s` / `Kafka` 等技术词误判薪资；51job 补齐前置过滤与同公司建联上限；修复 `8千-1.2万`、`10-15万/月`、`1.5-2.5w·14薪` 等薪资解析，以及周期计划每日不限额（`0`）与任务线程防死锁守卫。
