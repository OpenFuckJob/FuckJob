# OfferFlow v0.2.0

`v0.2.0` 是 OfferFlow 面向日常求职体验的一次大版本升级：围绕**「本地安全自动投递 + HR 沟通管家」**核心定位，全面重构产品主线、视觉体系与状态同步引擎，同时补齐反封号安全护栏与防噪过滤套件。

## 聚焦核心主线，3 分钟上手

- **顶层导航精简为 3 页签**：收敛为「自动投递（`⌘1`）· 沟通与进度（`⌘2`）· 求职设置（`⌘3`）」，移除偏离主线的「模拟面试」、工程调试用的「测试模式 Playground」及首日空窗的独立数据大屏，净精简超 6,000 行冗余代码与 16 MB 历史残留资源。
- **「自动投递」首页重做**：顶部一行紧凑今日战报条（安全额度进度条、HR 回复率、约面/Offer、待接手），主卡片集中呈现当前求职目标、3 盏就绪灯与一键开始按钮，运行日志默认折叠为底栏。
- **「求职设置」分层为「基础设置 + 高级设置」**：基础设置一屏 4 张清晰卡片（求职意向与一键屏蔽水岗、简历与沟通方式、3 选 1 傻瓜防封档位「保守 20/天 · 标准 40/天 · 积极 70/天」、可选 AI 大模型），多方案、正则表达式、自定义 Prompt、Webhook 与备份能力完整收拢在高级设置中。
- **首次引导重写**：改为 3 步直达首投（求职意向与 PDF 简历 → 浏览器与可选 BOSS 扫码 → 防封档位与可选 AI）。

## 零点击状态同步与求职看板升级

- **零点击被动同步（BOSS + 猎聘）**：摒弃逐张点击会话卡片的高风控方式，改为被动捕获会话列表接口 + 零点击 DOM 摘要与水位线增量剪枝，**不点开聊天窗、完全保留手机端/网页端未读红点**，即可把未读条数、HR 最新回复预览和平台状态拉平到本地看板。
- **双轨正向状态机 + 约面自动识别**：自动识别强约面信号并正向推进阶段，绝不覆盖用户手动拖到「面试中 / Offer / 已归档」的决策。
- **交互式 6 列求职看板**：支持跨泳道拖拽流转、点击阶段胶囊切换、可折叠归档列、红色未读角标、1 行最新消息预览、一键拉黑公司、批量删除、面试笔记与面试时间编辑，以及 UTF-8 BOM CSV（Excel 友好）与 Markdown 导出。

## 反封号安全护栏与防噪过滤

- **BOSS 零点击前置过滤**：点开详情前先基于列表卡片完成规则、真实薪资与同公司冷却判断，大幅减少无效详情浏览，并修复跳过岗位无停顿的问题。
- **每日投递安全上限与熔断护栏**：支持单平台每日建联上限、单轮熔断、同公司建联上限，默认开启标准拟人化节奏。
- **真实薪资解析与一键反噪预设**：支持最低月薪门槛、薪资跨度虚标倍数拦截、排除面议，以及 IT 外包 / 外包驻场 / 招转培 / 保险电销一键增量屏蔽词。
- **可选实时通知（Webhook）**：支持飞书 / 企业微信 / 钉钉 / Bark / 自定义 JSON，在待人工处理、风控中断或收到 HR 回复时及时提醒。

## 全新品牌 SVG 图标与桌面端 UI 重塑

- **全新品牌视觉**：设计全新几何 SVG 品牌标志（`O 环 + 45° 上升流箭头`）并更新全套 macOS / Windows 原生桌面图标，打造统一 1.75px 精工线性 SVG 图标集与 BOSS / 猎聘 / 51job 定制平台徽章。
- **浅色 / 深色双主题体系**：升级为 Signature Indigo 主色、Linear 风格多层曜石黑暗黑表面阶梯、居中毛玻璃胶囊导航与分级彩色日志终端。
