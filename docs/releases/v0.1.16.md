# OfferFlow v0.1.16

本版本将自动回复升级为完整的 AI 决策链路，引入浏览器自动化任务队列，并大幅增强猎聘平台的沟通能力与大模型降级容错。

## 新增与改进

### AI 决策链路与智能沟通
- **自动回复改为 AI 决策链路**：统一大模型调用入口，所有大模型调用与提示词收敛到统一的 Agent 循环，逻辑更清晰、更易维护。
- **新增对外发送闸门**：避免把模型的婉拒措辞直接发送给招聘方，保护沟通体验。
- **自动回复配置新增演练模式与发送边界**：支持在真实发送前演练 AI 回复，并控制发送范围。
- **队列任务失败原因写入运行日志**：任务失败时可追溯具体原因，便于排查。
- **修正 BOSS 未读会话的列表判定与去重**：未读消息识别更准确，避免重复处理。
- **修复启用 LLM 打招呼时模型生成内容被丢弃**的问题。

### 浏览器自动化任务队列
- **支持浏览器自动化任务队列与双平台并行**：BOSS 直聘与猎聘可并行执行任务。
- **支持多求职方案与任务快照路由**：不同求职方案互不干扰。
- **改进 BOSS 岗位列表滚动加载与运行反馈**。
- **修复调试端口被 ddns-go 等进程占用时无法启动浏览器**的问题。

### 猎聘平台
- **猎聘沟通改用 IM 接口取数**，并支持同意简历请求。
- **支持自动发送图片资源**。
- **登录校验改用用户信息接口**，并修复加载中误判。
- **请求记录器保留 IM 接口完整响应体**。

### 大模型降级链与重试策略
- **定义大模型降级链与可配置重试的数据契约**。
- **支持按降级链条目独立存储大模型密钥**。
- **大模型调用支持可配置重试与多提供商降级**：单一提供商故障时自动切换备选。
- **配置中心支持编辑大模型降级链与重试策略**。
- **调整主备顺序时密钥随服务一并对调**而非清除。
