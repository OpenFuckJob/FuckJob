让求职流程更可控。

Fuck Job 是一款开源桌面求职助手，支持岗位抓取、批量沟通、岗位分析、简历优化与模拟面试。所有核心数据都保存在本机，你决定是否接入 AI。

⬇️ 下载最新版 GitHub 源码
本地运行配置、简历、岗位和聊天数据保存在本机。
自动化求职支持 BOSS 直聘、猎聘的岗位抓取与沟通流程。
AI 可选兼容本地模型与 OpenAI 兼容接口。
开源可审计Apache-2.0 许可，网络边界透明可查。

Features

核心功能，保持清晰。

官网只保留用户最关心的信息：能做什么、数据是否安全、如何下载使用。

🖥️

工作台

控制环境检测、扫码登录、岗位抓取、批量沟通和实时日志。

📋

岗位管理

集中管理岗位数据，按薪酬、经验、学历、行业和规则筛选。

🤖

AI 分析

用于岗位匹配、沟通话术、聊天回复、简历优化和模拟面试。

⚙️

配置中心

统一配置浏览器、模型、简历、筛选规则和沟通策略。

🔐

凭据安全

API Key 存系统钥匙串或凭据库，不写入普通配置文件。

🧪

边界检查

可通过脚本检查出站请求，配合开源代码进行审计。

Screens

Workspace

自动化任务工作台

任务状态、运行日志和平台操作集中在一个界面中，便于观察与干预。

Config

配置中心

管理浏览器、模型、简历、岗位筛选和沟通话术，让自动化行为更可控。

Analysis

岗位分析

结合岗位描述与简历上下文，辅助判断匹配度、风险点和沟通重点。

Interview

模拟面试

围绕目标岗位生成面试问题和准备方向，帮助快速复盘表达。

Privacy First

不把求职数据交给黑盒服务。

Fuck Job 默认本地保存数据，无账号体系、无遥测、无云端同步。AI 是可选能力，你可以使用本地模型，也可以接入自己信任的服务。

查看隐私与网络文档
✅ 配置、岗位、聊天、简历数据仅存储在本机
✅ 密钥进入系统钥匙串 / 凭据库
✅ 敏感日志自动脱敏
✅ 可运行网络边界检查脚本

Get Started

下载最新版，配置后开始使用。

下载链接固定指向 GitHub 最新 Release，不需要手动维护版本号。

打开最新 Release
1

下载安装包

进入最新 Release 页面，选择与你系统匹配的安装包。

2

完成本地安装

macOS 未签名版本如被拦截，可移除隔离标记。

xattr -dr com.apple.quarantine /Applications/fuckJob.app
3

进入配置中心

设置浏览器、简历、筛选规则和可选 AI 模型，然后启动任务。
