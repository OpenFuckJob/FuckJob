Step 01

安装软件

从 GitHub Releases 页面下载与你系统匹配的安装包：github.com/OpenFuckJob/FuckJob/releases。

macOS 未签名版本如被系统拦截，可在终端执行 xattr -dr com.apple.quarantine /Applications/fuckJob.app 后重新打开。

Step 02

初始化配置

首次启动后，先完成浏览器环境和大模型两项基础配置。

1. 浏览器环境配置

软件会自动检测本地已安装的 Chrome 内核浏览器，优先识别 Google Chrome，其次为 Microsoft Edge。

如果已安装 Google Chrome 但未被检测到，请打开浏览器访问 chrome://version，手动复制可执行文件路径并填入配置；Edge 浏览器对应的地址是 edge://version。

2. 大模型配置

熟悉大模型 API 调用的用户可自行配置；不熟悉的可以按下面的步骤使用 DeepSeek。先进入 DeepSeek 开放平台，建议先充值少量金额（按实际使用量扣费）。

回到软件的「配置中心 → 大模型」，选择 DeepSeek，填入 API Key 和模型名称。

请先保存凭证信息，再点击验证连接。

未保存就验证会因为读不到密钥而失败。API Key 会写入系统钥匙串／凭据库，不会保存在普通配置文件中。

Step 03

简历配置

进入「配置中心 → 求职方案 → 简历配置」，上传 PDF 格式的简历文件，并开启「注入 LLM 上下文」。

  • 简历附件：选择 PDF 文件后会自动解析出文本，解析结果可以在「简历内容」中手动调整。
  • 注入 LLM 上下文：开启后，打招呼、自动回复和岗位分析都会带上简历内容，生成结果才会贴合你的真实经历。

Step 04

岗位筛选

在配置中心根据个人需求设置岗位筛选条件，常用的几项：

  • 公司关键词：包含或排除指定公司，直接过滤掉不想投的对象。
  • 目标岗位要求：用自然语言描述你想要的岗位，供 AI 复核时参考。
  • 高级筛选：支持正则匹配规则，也可以让 AI 帮你生成规则。
  • AI 岗位意图复核：关键词和正则规则筛选通过后，再根据岗位职责复核一次；复核失败或模型异常时会跳过岗位，避免误投。开启后可以识别描述虚假或明显偏离的岗位。

建议同时开启拟人化，让操作节奏更接近真人，降低被平台风控识别的概率。

Step 05

打招呼配置

开启 LLM 打招呼功能，并按需填写提示词。下面这份模板可以直接复制使用： 

你是一个求职者，正在BOSS直聘上与招聘方沟通。请根据以下内容生成一段开场的打招呼用语。

【严格要求】
1. 严禁使用任何占位符，例如“X年”、“Y年”、“某技术”、“XX公司”等。也不要用括号标注“待补充”之类的内容。
2. 如果简历（见下方“我的简历”）为空或缺少某些信息（如工作年限、具体技能），请使用模糊但自然的说法，例如“我有相关经验”、“熟悉该领域”、“有多年实践经验”等。绝对不能编造具体数字或占位符。
3. 必须保证生成的文本是可以直接发送给HR的完整句子，无需人工修改。
4. 总字数控制在60~120字。
5. 结尾以开放式提问结束，例如“方便进一步沟通吗？”或“您觉得我的方向匹配吗？”。

【示例】
简历为空或信息很少时，正确写法：
“您好，我对贵公司招聘的Java开发岗很感兴趣。我熟悉Spring Cloud等微服务框架，有相关项目经验。看到岗位中涉及高并发系统设计，这正是我所擅长的方向。方便进一步沟通吗？”
错误写法（包含占位符）：
“我有X年Java经验” 或 “我有3年经验（但实际上没有提供）”。

=== 我的简历（可能为空） ===
{{resume_context}}

=== 当前岗位信息 ===
{{job_content}}

请直接输出打招呼文本，不要加额外解释。
{{resume_context}} 自动替换为简历配置中的简历文本（可能为空）。
{{job_content}} 自动替换为当前正在沟通的岗位信息。

建议再补充一份简历图片，HR 无需下载附件就能直接预览你的基本信息，回复率通常更高。

Step 06

自动回复

如希望简化沟通流程，可选择「仅 AI 回复」模式，并填写自动回复提示词：

你现在是一名在 Boss直聘 平台上和 HR 沟通的求职者。

系统会提供以下上下文：

1. 当前岗位信息；
2. 求职者个人简历；
3. 历史聊天记录；
4. 额外补充说明（可选）。

你的任务：

* 结合上下文，生成一条适合发送给 HR 的回复；
* 回复风格真实自然，符合中文求职聊天习惯；
* 回复要简短，不啰嗦，避免长篇大论；
* 保持礼貌、职业化，但不要过于正式；
* 优先突出岗位匹配度、沟通意愿、到岗时间、项目经验等关键信息；
* 如果 HR 提问，直接回答问题，不要答非所问；
* 如果信息不足，可以礼貌追问；
* 避免模板化、机械化表达；
* 输出仅包含最终回复内容，不要添加解释。

输入格式：
【岗位信息】
{{job_description}}

【个人简历】
{{resume}}

【额外补充】
{{background_context}}

【历史聊天】
{{chat_history}}

请生成一条适合发送给 HR 的简短回复。
{{job_description}} 当前岗位的职位描述。
{{resume}} 简历配置中的个人简历文本。
{{background_context}} 你额外补充的说明，例如到岗时间、薪资预期。
{{chat_history}} 与该 HR 的历史聊天记录。

Step 07

岗位分析

岗位分析会结合岗位描述与简历上下文，辅助判断匹配度和沟通重点。该功能可根据需要选择性开启，不开启也能正常投递。

Step 08

启动运行

1

先执行环境检查

软件会自动检测浏览器环境和 BOSS 直聘账号登录状态。如未登录，会展示登录二维码，使用 BOSS 直聘 App 扫码即可。

2

在「工作台」中添加任务并开始运行

创建任务后即可开始运行，任务状态与实时日志都会显示在工作台，可随时暂停或干预。

FAQ

常见问题

已安装 Chrome，但软件检测不到浏览器

打开 chrome://version（Edge 为 edge://version），复制「可执行文件路径」并手动填入浏览器环境配置。

大模型测试连接失败

先确认已经保存凭证再点击验证；然后检查 API Key 是否有效、模型名称是否填写正确、平台账户是否还有余额。

打招呼内容里出现「X年」这类占位符

保留提示词中【严格要求】的第 1、2 条，并确认简历配置里已开启「注入 LLM 上下文」，否则模型拿不到真实信息就会编造占位符。

担心被平台风控

开启拟人化，控制单次任务的投递量，并合理适度使用自动化功能，遵守平台服务条款。
